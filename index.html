      Install SuperCollider to get started
      
    
      AnInstrument writes SuperCollider code and plays it with SuperCollider, a free, open-source audio engine. It isn't installed on this Mac yet.
      
    
        
      
      1. Download SuperCollider for macOS (free).
        2. 
      
      2. Open the downloaded file and drag SuperCollider into your Applications folder.
        3. 
      
      3. Open SuperCollider once so macOS can confirm it's safe to run, then quit it. AnInstrument runs its own copy in the background, and the two can't both play at once.
        4. 
      
      4. Come back here and click Check again.
        5. 
    
      
    
      Using Homebrew? brew install --cask supercollider works too.
